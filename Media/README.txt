Shared binary assets (textures, fonts, link icons).

This folder is intentionally shared across all client trees because it
contains no executable code. Code stays isolated per client under src/.

The current scaffold renders with built-in Blizzard textures only, so most
files are still to come. Drop custom bar/border textures and the About
link icons (discord/github/curseforge/wago/kofi .tga) here later and
reference them from each client's Core/Media.lua and Core/About.lua.

Fonts/TitilliumWeb-Bold.ttf - the UI font (M.font in Core/Media.lua).
SIL Open Font License 1.1, see Fonts/TitilliumWeb-OFL.txt. Freely
redistributable bundled with the addon; do not sell it standalone.

Textures/NucleusBar.tga - "Nucleus Gloss" bar fill (M.barTextures.nucleus3 in
Core/Media.lua). Procedurally generated, not drawn or copied: an 8x64,
32bpp, uncompressed grayscale gradient (bright band near the top easing
to a darker base) written directly as raw TGA bytes. Grayscale so
SetStatusBarColor's tint lands on the exact class/custom color.

Textures/NucleusBar2.tga - "Nucleus 2" bar fill (M.barTextures.nucleus2).
Same family, no shading: an 8x8 uniform white TGA, same generation
method as NucleusBar.tga. Visually equivalent to "Flat" (Interface\
Buttons\WHITE8X8) - kept as its own named/branded option rather than
pointing users at the Blizzard one.

Textures/NucleusShield.tga - the "Striped" shield/heal-absorb overlay
option (M.shieldTextures.striped, Appearance > Shield Settings).
Procedurally generated: a 16x16, 32bpp TGA, white RGB with the alpha
channel forming a 45-degree hazard-stripe pattern, tiled horizontally
via SetHorizTile. Alpha-only so SetStatusBarColor's tint (and its own
alpha) lands the configured shield color with real texture instead of
a flat wash - same underlying idea as Cell/Ellesmere's own shield art,
not copied from either.

Textures/NucleusRound.tga, NucleusRoundSm.tga, NucleusCircle.tga,
NucleusShadow.tga - shape textures for the options window (M.tex in
Core/Media.lua): 9-sliced rounded rectangles (32px r8 / 16px r4), a dot,
and a soft drop shadow. White RGB with the shape in the alpha channel,
tinted with SetVertexColor. Procedurally generated by
tools/gen_textures.ps1 (re-run it to change radii or blur).
Textures/NucleusBar3.tga - the default "Nucleus" bar fill (M.barTextures.nucleus).
8x8 opaque uniform grey (76.5%), generated by tools/gen_textures.ps1
(BarFlat). Grey rather than white so the class colour is multiplied down
to a flat, deeper tone; the level was matched against Ellesmere's rendered
health bar (class colour x ~0.76), not copied from any asset.

Textures/NucleusGear.tga - the settings cog on the indicator preview card
(M.tex.gear). 32x32, white RGB with the shape in alpha (8 teeth, centre
hole), tinted with SetVertexColor; generated by tools/gen_textures.ps1.

Textures/NucleusRoles.tga - the square role icons (M.tex.roles, Indicators >
Role Icon > Square / Square 2). 128x64, 32px tiles (tank shield / healer cross /
damage sword). Row 1: bright rounded squares with a white glyph. Row 2: flat
dark tiles with a role-coloured rim and a tilted sword; the fourth column is
empty. Generated by tools/gen_textures.ps1 (RoleIcons), not
drawn or copied. The Circle shape uses Blizzard's own round role sheet.

Logo.tga  128x128 addon logo (TOC icon, minimap button, window header).
          Built from tools/logo/nucleus_logo.png by tools/gen_logo.ps1.
